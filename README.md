# REAL · מצגת קונספט

מצגת אינטראקטיבית (עמוד יחיד) לרעיון של REAL: רשת חברתית מקומית שבה כל תמונה צולמה עכשיו, במקום שמופיע, על ידי אדם אמיתי.

- `index.html`: 29 השקפים, בארבעה פרקים (החזון · אפיון מוצר · אפיון ממשק · עסק וצמיחה).
- `styles.css`: עיצוב כהה בצבעי האפליקציה, אנימציות וגרסת מובייל.
- `app.js`: מנוע השקפים והחלקים האינטראקטיביים (תרחיש בקשת רגע, צילום ← פרסום ← מפה, מפת מסכים, קהל, מיקום ועוד).

בלי תלויות ובלי build. פונטים: Heebo ו-Montserrat מ-Google Fonts.

## ניווט
גלגלת, חיצים במקלדת, החלקה, או הסרגל התחתון: פרקים, כפתור ״הבא״ בסגנון כפתור הצילום, הקודם, הצגה אוטומטית ומסך מלא (גם `F`). אפשר לקשר לשקף מסוים עם `#id`, למשל `index.html#requests`. בטלפון השקפים נערמים לגלילה רגילה.

## פריסה
אתר סטטי. ב-Vercel: לייבא את הריפו בלי Framework Preset ובלי Build Command, וכל push ל-`main` מתפרסם אוטומטית.
